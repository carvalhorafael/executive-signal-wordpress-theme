Tema WordPress do Executive Signal.

== Description ==

Executive Signal WordPress Theme e a camada de apresentacao WordPress para experiencias editoriais e institucionais do Executive Signal.

O tema prioriza uma arquitetura hibrida: templates PHP classicos, suporte forte ao editor de blocos, `theme.json`, block patterns e assets compilados com Vite.

== Development ==

Use o ambiente local com wp-env:

1. npm install
2. npm run wp:start
3. npm run composer:install
4. npm run dev

Para validar e gerar o pacote distribuivel:

1. npm run validate
2. npm run theme:zip
